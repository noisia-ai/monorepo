# Editorial consolidation in Studio

Numeric preparation remains free. **View editorial estimate** makes an explicit unpaid read, with loading feedback, to build the forecast and obtain the existing opaque policy quote. The forecast includes screening and all three global stages using expected input/output tokens. It is a forecast, separate from any explicitly configured hard cap; settled usage remains the source of actual cost.

The user checks the confirmation, then selects **Start editorial review**. The browser submits the opaque quote reference and the existing same-key admission command. Source, policy and quote are revalidated by the existing atomic admission; the Worker still owns provider transport, manifests, global stages and materialization. Quote expiry disables initiation and requires a new read. An uncertain admission response retains its same command/key for replay. The earlier unconfirmed start endpoint can recover an existing same-key intent only; it cannot create new paid work.

The browser never receives the private plan, evidence or provider configuration. GET alone does not reserve exposure, enqueue jobs or contact the provider. Loading, failures, confirmed cost, reserved cost and ambiguous exposure remain visible. A completed catalog remains separate from adoption and Signal selection.
