# Inferencia por mención de intereses — LOCAL

24 septiembre 2026. Este corte continúa la entrada editorial y el enlace de evidencia ya documentados. No sustituye sus recibos ni la entrega separada de Signal desde importación.

El adaptador `signal-topic-interest-root-inference.ts` utiliza el lector paginado de clasificación existente para recorrer cada raíz y todos sus fragmentos. Un evaluador inyectado debe dar una relación para **cada interés definido**. La shortlist editorial es sólo una pista. Una relación `supports` produce una decisión modelo **pendiente** únicamente cuando cita un fragmento validado de esa misma raíz; `mixed` e `insufficient` dejan la raíz sin resolver, y la ausencia de un interés nunca se interpreta como rechazo. Una corrección humana vigente prevalece sobre el resultado modelo. Se comprueban identidad de revisión, catálogo, definiciones, cobertura íntegra, citas y checkpoint del escritor. Un mismo ID de catálogo no puede representar dos intereses.

La prueba sintética incluye tres raíces, dos intereses y fragmentos paginados: una raíz con soporte específico, una corrección humana y una candidata editorial mixta que no se convierte en membresía. También comprueba fallo por revisión o definición alterada, cobertura incompleta y cita falsa. Resultado: tres pruebas focales; suite Worker 629 PASS/42 SKIP, cero fallos; typecheck Worker PASS y `git diff --check` PASS. Los dos archivos de Worker quedan sólo en este checkout focal.

**No es clasificación entregada.** El evaluador de prueba es simulado; no hay modelo/proveedor real, dispatcher, aceptación PostgreSQL de esta composición, reuso de raíces inalteradas ni lectura de Signal para estos intereses. El digest de candidatos por sí solo no autentica una entrada externa: el futuro dispatcher debe cargar el snapshot inmutable de SQL0183 y comprobar vigencia, derechos, perfil y huellas antes de ejecutar. El `catalog_digest` de este adaptador debe sellarse con el catálogo canónico de la ejecución, no reconstruirse desde una lista del cliente. Las decisiones modelo siguen pendientes y no implican aprobación ni publicación.
